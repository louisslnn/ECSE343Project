\begin{abstract}
This report details the estimation of unknown resistance ($R$) and capacitance ($C$) values in a half-wave rectifier circuit[cite: 268]. We implement a physics-based simulator using the Backward Euler method and Newton-Raphson iteration[cite: 102, 112]. Two primary estimation methods are compared: the classical Gauss-Newton non-linear least-squares algorithm and a supervised learning approach using models such as Random Forest and MLP[cite: 124, 294]. Our results compare the robustness, accuracy, and efficiency of both methodologies[cite: 301].
\end{abstract}

\subsection{Modified Nodal Analysis (MNA)}

$$Gx(t) + C\dot{x}(t) + f(x(t)) = b(t)$$

$$\Psi(x_t) = (G + \frac{1}{\Delta t}C)x_t + f(x_t) - (b_t + \frac{1}{\Delta t}Cx_{t-1}) = 0$$
