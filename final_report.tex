\begin{abstract}
This report details the estimation of unknown resistance ($R$) and capacitance ($C$) values in a half-wave rectifier circuit[cite: 268]. We implement a physics-based simulator using the Backward Euler method and Newton-Raphson iteration[cite: 102, 112]. Two primary estimation methods are compared: the classical Gauss-Newton non-linear least-squares algorithm and a supervised learning approach using models such as Random Forest and MLP[cite: 124, 294]. Our results compare the robustness, accuracy, and efficiency of both methodologies[cite: 301].
\end{abstract}

\section{Introduction}
Estimating circuit parameters is a fundamental inverse problem[cite: 273]. We are tasked with identifying $R \in [1\Omega, 2.5k\Omega]$ and $C \in [0.1\mu F, 5\mu F]$ from noisy time-domain measurements of $V_1, V_2, V_3$, and $I_E$[cite: 11, 281]. This report covers the derivation of the circuit's sensitivity, the implementation of a numerical simulator, and a comparative analysis of data-driven models[cite: 173, 201].

\section{Deriving the Jacobian of the non linear element for algorithm 1}

The non linear element is modeled by the function $f$ which is given by the following equation:
$$f(\begin{bmatrix}V_1\\V_2\\V_3\\I_E\end{bmatrix}) = \begin{bmatrix}
0 \\
I_s(e^{\frac{V_2 - V_3}{V_t}} - 1) \\
-I_s(e^{\frac{V_2 - V_3}{V_t}} - 1) \\
0
\end{bmatrix}$$
Applying the principles of differentiation, we find that the derivative of $f$ with respect to the state vector $x$ is given by the Jacobian matrix $J$ which is defined as follows:
$$J = \frac{\partial f}{\partial x} = \begin{bmatrix}
0 & 0 & 0 & 0 \\
0 & \frac{I_s}{V_t}e^{\frac{V_2 - V_3}{V_t}} & -\frac{I_s}{V_t}e^{\frac{V_2 - V_3}{V_t}} & 0 \\
0 & -\frac{I_s}{V_t}e^{\frac{V_2 - V_3}{V_t}} & \frac{I_s}{V_t}e^{\frac{V_2 - V_3}{V_t}} & 0 \\
0 & 0 & 0 & 0 
\end{bmatrix}$$

\begin{algorithm}
\caption{getSensitivities Function}
\begin{algorithmic}[1]

 \Function{GetSensitivities}{$\mathbf{x}_{\text{pred}}, G, C, R, \delta t$}
        \State $\mathbf{dxdR} \gets [\,]$
        \State $\mathbf{dxdC} \gets [\,]$
        \State $\frac{\partial G}{\partial R} \gets$ \Call{get\_dGdR}{$R$}
        \State $\frac{\partial C}{\partial C} \gets$ \Call{get\_dCdC}{}

        \For{$i = 0, 1, \dots, |\mathbf{x}_{\text{pred}}| - 1$}
            \State $J \gets$ \Call{get\_jac}{$\mathbf{x}_{\text{pred}}[i]$}
            \State $A \gets G + \dfrac{C}{\delta t} + J$

            \If{$i = 0$}
                \State $\mathbf{tmp}_R \gets -\dfrac{\partial G}{\partial R}\, \mathbf{x}_{\text{pred}}[i]$
            \Else
                \State $\mathbf{tmp}_R \gets -\dfrac{\partial G}{\partial R}\, \mathbf{x}_{\text{pred}}[i] + \dfrac{C}{\delta t}\, \mathbf{dxdR}[i-1]$
            \EndIf
            \State Append $A^{-1}\, \mathbf{tmp}_R$ to $\mathbf{dxdR}$

            \If{$i = 0$}
                \State $\mathbf{tmp}_C \gets -\dfrac{\partial C}{\partial C}{\delta t}\, \mathbf{x}_{\text{pred}}[i]$
            \Else
                \State $\mathbf{tmp}_C \gets -\dfrac{\partial C / \partial C}{\delta t}\!\left(\mathbf{x}_{\text{pred}}[i] - \mathbf{x}_{\text{pred}}[i-1]\right) + \dfrac{C}{\delta t}\,\mathbf{dxdC}[i-1]$
            \EndIf
            \State Append $A^{-1}\, \mathbf{tmp}_C$ to $\mathbf{dxdC}$
        \EndFor

        \State \Return $\mathbf{dxdR},\, \mathbf{dxdC}$
    \EndFunction

\end{algorithmic}
\end{algorithm}
